# Python 系统化课程

浏览器里的 Python 自学课程：**6 章 30 节完整教程**，约 6.2 万字、建议 15 小时。以理解为核心——教程是主体，练习放在文末用于巩固；运行与改错类练习在浏览器内由**真实 Python**（Pyodide）判定，不靠字符串匹配。

## 快速开始

需要 Node.js ≥ 18。项目没有依赖包，不需要 `npm install`。

```bash
node server.js          # 本地预览 http://localhost:8081/
```

然后用浏览器打开 `http://localhost:8081/index.html`。**不要用 `file://` 直接打开**：课程数据通过 `fetch()` 加载，Pyodide 的 module worker 也要求 HTTP 环境。

**分享给好友**：打开 `http://localhost:8081/share.html`，这是为分享准备的卡片页，展示课程亮点与目录；点「复制分享链接」即可把地址发给好友。部署后把 `localhost:8081` 换成站点域名。

重新生成课程数据（修改教程或考点后必须执行，约 40 秒）：

```bash
node build-course-v6.mjs
```

该命令会做三件事：合并 `course/ch1..ch6.mjs` 的教程与 `data/levels.json` 的练习数据、用系统 `python3` 实跑校验全部 60 个教程代码块与 30 道预测题、写出 `data/course.json`。校验不通过会逐条报错并以非零状态退出，不会产出半成品。

## 课程结构

| 章 | 主题 | 节号 |
|---|---|---|
| 1 | Python 入门 | 1–5 |
| 2 | 输入与条件判断 | 6–10 |
| 3 | 循环与容器 | 11–15 |
| 4 | 函数与文本处理 | 16–20 |
| 5 | 文件与程序健壮性 | 21–25 |
| 6 | 面向对象与进阶特性 | 26–30 |

每节是一份可独立阅读的教程，含 9 个结构化块：开场引子、概念讲解（2–4 段）、可运行示例与真实输出、逐行讲解、语法速查表、常见错误（错误写法 / 原因 / 正确做法）、知识小结、巩固练习解析。正文平均 2080 字。

首页是课程大纲：章节导航、课时卡片（目标、时长、字数、示例数）、学习进度。**每次打开都从第一章开始**，只有主动点击章节标签才切换。勾选"标记为已学完"后，进度保存在浏览器本地（`localStorage` 的 `pycourse:completed`）。

## 练习方式

每节**只显示一种**答题方式，按本节考点自动选定，无需切换页签：

| 方式 | 选用于 | 节数 | 判定 |
|---|---|---|---|
| 运行验证 | 综合编写类考点 | 8 | Pyodide 实际运行，归一化后比对 stdout |
| 预测输出 | 结果推断类考点 | 7 | 单选；选项每次随机排列 |
| 找错改错 | 典型错误类考点 | 8 | Pyodide 实际运行，比对 stdout |
| 配对分类 | 概念辨析类考点 | 7 | 左右两列配对，支持键盘操作 |

所有练习共用三组辅助：

- **考点标签**：说明本题考什么。
- **三级提示**：方向 → 知识要点 → 常见错误原因，逐级展开，不直接给出答案。
- **查看解析**：答案讲解放在这里，答错时不会看到正确代码。

运行与改错在输出不符时显示**期望输出 vs 实际输出的逐行差异**，并标出首个不一致行。改错题干只描述程序意图与现象，不泄露错误位置。

练习只给诊断反馈，不自动跳到下一节。

## 数据与构建

`data/course.json` 是**生成物**，不要直接编辑。改内容要走源头：

```
course/ch1..ch6.mjs       ─┐
course/SCHEMA.md          ├─→ build-course-v6.mjs ─→ data/course.json
course/practice-meta.mjs  ─┤        │
data/levels.json (v5.1)   ─┘        └─→ python3 实跑校验
```

- `course/chN.mjs`：教程正文与代码块。每章 5 节，字段规范见 `course/SCHEMA.md`。
- `course/practice-meta.mjs`：30 节的考点（`concept`）、不泄露答案的改错题干（`debug`）、每节选用的答题方式（`primaryMode`），以及第 5 节的语境对齐覆盖数据。
- `data/levels.json`：v5.1 的练习题库，作为 `run` / `predict` / `debug` / `match` 四类的判定数据源，保留不可删除。
- `build-course-v6.mjs`：生成器，产出 v6.2.0 课程数据。

编辑教程时，`code` 与 `output` 一律用 `String.raw` 标签模板，以保留 Python 源码里的反斜杠转义；不需要核对输出的展示性代码片段设 `output: null`。生成器会校验：课程块输出与 `python3` 实跑一致、预测题正确项等于真实输出、改错代码确实无法得到期望输出、题干与反馈无答案泄露。

## 页面与实现

| 文件 | 职责 |
|---|---|
| `share.html` + `css/share.css` | 分享落地页：深色科技风卡片，展示课程亮点与目录，可复制链接发给好友 |
| `index.html` + `js/course.js` | 课程大纲：章节 tab、课时列表、进度统计 |
| `level.html` + `js/lesson.js` | 课时页：教程排版、单一答题区、提示与解析、进度标记 |
| `css/tokens.css` | 设计令牌：深色为主 + 青/电光蓝点缀，含浅色变体 |
| `css/base.css` | 基础层：深色底、固定在 `html` 上的极光与网格底纹、焦点环、reduced-motion |
| `css/style.css` | 组件与教程排版样式 |
| `js/py-runner.js` + `js/py-runner.worker.js` | Pyodide 封装：Web Worker、stdin 注入、输出捕获、8 秒超时终止重建 |
| `server.js` | 零依赖本地服务器（8081） |

视觉语言与同仓库外的博客「墨迹」统一为深色科技风。深浅主题由 `data-theme` 控制，`:root` 默认深色。

`js/game.js` 与 `js/level.js` 是 v5 及更早的旧引擎，当前页面已不引用；保留在仓库中仅作历史参考。

## 已知限制

- 运行与改错类练习首次使用需联网从 jsDelivr 加载 Pyodide v0.27.2（约 10 MB）；预测与配对类离线可用。
- 进度只存在当前浏览器的 `localStorage`，不跨设备同步。
- 本机无 Chromium 内核，未做浏览器像素级渲染验证；已验证范围为数据、语法、令牌引用、元素 ID 与 HTTP 资源可达性。
- 静态文件需通过 HTTP 访问，`file://` 下 `fetch()` 与 module worker 会被浏览器拦截。
