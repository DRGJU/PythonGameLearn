# 课程数据结构规范（v6）

每章一个文件 `course/chN.mjs`，导出 `default` 对象：

```js
export default {
  id: 1,                       // 章号 1..6
  title: 'Python 入门',         // 章名，学术化，不用游戏化措辞
  subtitle: '一句话说明本章目标',
  intro: '2~3 句章节导语，说明本章在整门课中的位置与学完能做什么',
  lessons: [ /* 5 个 lesson 对象，见下 */ ]
};
```

## lesson 对象

```js
{
  id: 1,                        // 全局课号 1..30，与 chN 对应（ch1:1-5, ch2:6-10 ...）
  title: '认识 Python：从 print() 开始',   // 禁止出现「关卡/通关/挑战/冒险/大师/新手村」
  minutes: 25,                  // 预计学习分钟数 15~40
  objectives: ['学完能……', '……'],  // 3~4 条可衡量的学习目标
  blocks: [ /* 见下，按顺序渲染 */ ]
}
```

## blocks 类型（每种可出现多次）

| type | 字段 | 说明 |
|------|------|------|
| `lead` | `text` | 开场引子，1 段，说明为什么需要这个知识 |
| `prose` | `title`, `paras: string[]` | 概念讲解，2~4 段，每段 80~200 字，讲清「是什么/为什么/怎么用」 |
| `code` | `title`, `code`, `output`, `explain: string[]`, `stdin?: string[]` | 完整可运行示例；`explain` 逐行/逐要点讲解；`output` 为**程序真实标准输出字符串**，`output: null` 表示仅展示语法不校验 |
| `table` | `title`, `head: string[]`, `rows: string[][]` | 语法速查 / 对比表，2~5 列、3~8 行 |
| `pitfalls` | `title`, `items: {wrong, why, right}[]` | 常见错误与坑，3~4 条；wrong 是错误写法或现象，why 是原因，right 是正确做法 |
| `summary` | `title`, `items: string[]` | 知识小结，4~6 条要点 |
| `review` | `title`, `paras: string[]` | 练习解析：说明本节 4 类巩固练习分别考查什么、易错点在哪、如何自查 |

## 硬性要求

1. **每节正文合计 1500~2500 个中文字符**（不含代码），宁可讲透一个点，不要堆砌术语。
2. `code` 块必须是**完整、可直接运行的 Python 3 程序**：不依赖第三方库、不读外部文件、不使用随机/时间/网络、不含 `input()` 除非在 `stdin` 提供对应行。
3. `output` 必须与程序真实 stdout **逐字符一致**（含换行、含中文），生成器会用系统 `python3` 实跑校验；不确定时把该块设为 `output: null`。
4. 中文标点，代码与标识符用 ASCII 直引号；技术名词首次出现给英文原名（如「字符串（str）」）。
5. **禁止游戏化表达**：关卡、通关、冒险、挑战、大师、新手村、升级、打怪、庆祝、角色、金币、成就。用「课 / 节 / 章 / 练习 / 示例 / 小结」。
6. 不虚构版本号、性能数字、未经证实的结论；讲原理就讲准确的原理。
7. 难度循序渐进：第 1 章零基础，第 6 章可涉及装饰器/生成器原理。
8. 只导出 `default`，不要 `import` 任何东西，不要写注释以外的 JS 逻辑。
9. **`code` 与 `output` 一律用 `String.raw` 标签模板**（反引号），以保留 Python 源码里的 `\n`、`\t`、`\\` 等反斜杠转义，避免被 JS 当作自身转义吞掉。`output` 的首尾多余换行由生成器归一化，不影响比对。

## 章节与课号分配

| 文件 | 章 | 课号 | 主题 |
|------|----|------|------|
| ch1.mjs | 1 Python 入门 | 1-5 | print 输出、变量、数字运算、字符串、综合练习 |
| ch2.mjs | 2 输入与判断 | 6-10 | input、类型转换、if、if-else、综合练习（计算器） |
| ch3.mjs | 3 循环与容器 | 11-15 | while、列表、for 遍历、列表操作、字典 |
| ch4.mjs | 4 函数与文本 | 16-20 | 函数定义、参数、作用域、字符串方法、综合练习（猜数字） |
| ch5.mjs | 5 文件与健壮性 | 21-25 | 文件读写、异常处理、列表推导式、字典进阶、模块导入 |
| ch6.mjs | 6 面向对象与进阶 | 26-30 | 类与对象、继承、装饰器、生成器、综合项目（成绩册） |

练习数据（run/predict/debug/match）由生成器从 `data/levels.json` 直接复用，**章节文件不要写练习题**。
